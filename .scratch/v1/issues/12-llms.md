# 12: honoka-llms (agent-first)

`llms(app, ...)` serves /llms.txt (index of endpoints, llmstxt.org format) and /llms-full.txt (parameters, request bodies, responses per endpoint) generated from the route table through honoka-openapi's document. Scalar's API Reference has no llms.txt feature (checked its configuration), so this is ours.
