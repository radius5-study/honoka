# honoka-openapi

An OpenAPI 3.1 document and an API reference page, built from the routes you already have.

```python
from honoka_openapi import docs

docs(app, title="Taskboard API", version="1.0.0")
# GET /openapi.json   the document
# GET /docs           a Scalar reference page
```

`docs(app, *, title="API", version="0.1.0", path="/docs", spec_path="/openapi.json",
scalar_url=..., scalar_integrity=...)`. The document is built on each request from
`app.route_table()`, so routes registered after the call appear too. The page loads Scalar from a
pinned jsDelivr URL with a Subresource Integrity hash; pass `scalar_url` (and its hash, or `None`)
to serve your own copy. `build(app, title=, version=)` returns the document as a dict if you want
to write it to a file.

## Where each part comes from

| In the document | Taken from |
|---|---|
| path, method, `operationId` | the route and the handler's name |
| `summary`, `description` | the handler's docstring (first line, then the rest) |
| path parameters | the path pattern (`{id:int}` is an integer; `{id}` a string) |
| query, header, cookie, path parameters | `validator(query=, header=, cookie=, param=)` Structs |
| request body | `validator(json=)` or `validator(form=)` |
| success response | the handler's return annotation, `Json[T]` |
| success status | the `status=` option on the route (default 200) |
| other responses | the `responses=` option |
| `400` | added when the route validates anything |

```python
app.post(
    "/users",
    validator(json=NewUser),
    create_user,                       # async def create_user(c) -> Json[User]: ...
    status=201,
    responses={409: (ErrorBody, "The email is already registered")},
)
app.get("/health", health, openapi=False)      # leave a route out
```

`responses` maps a status to a type, or to `(type, description)`. HEAD and OPTIONS routes and
routes with a wildcard segment are left out, since OpenAPI cannot describe them. Schemas are
generated by msgspec, so any `msgspec.Struct` works, with its constraints (`msgspec.Meta`).
The same document feeds [`honoka-llms`](../honoka-llms).
